# 家計簿アプリ 使い方ガイド

スマホで使える家族共有の家計簿PWA。レシートを撮影するだけで自動入力でき、資産管理や将来のシミュレーションもできます。

アプリを開いたら「Google でログイン」をタップし、Google アカウントで認証します。

## 1. レシートを記録する

### カメラで撮影（自動入力）

1. ホーム画面で **「📷 カメラで撮影」** をタップ
2. レシートを撮影（または **「🖼 ライブラリから選択」** で複数選択可）
3. **「🔍 OCR で読み取る」** をタップ
4. 読み取り結果を確認・修正して **「💾 Google Sheets に保存」**

> 複数枚まとめて読み取ることができます。読み取り結果を1件ずつ確認しながら保存します。

### 手動で入力

1. ホーム画面で **「✏️ 手動で入力」** をタップ
2. 日付・カテゴリ・支払先・金額・使用者を入力
3. **「💾 Google Sheets に保存」**

### 自動保存モード

「自動保存」をオンにすると、OCR 読み取り後に確認画面を省略して自動保存します。連続入力に便利です。

### OCRモデル・解像度の切替

ホーム画面でモデルと解像度を選択できます。

| 設定 | 選択肢 | 特徴 |
|---|---|---|
| モデル | Haiku | 速い・安価 |
| モデル | Sonnet | 精度高め |
| 解像度 | 低〜高 | 高いほど精度が上がるが遅くなる |

## 2. 家計を集計する 📈

ホーム右上の **📈** をタップします。

### 月次タブ

- 当月の支出を **カテゴリ別円グラフ** で表示
- 予算が設定されているカテゴリは **予算ライン付きの棒グラフ** で比較表示
- **‹ ›** で前後の月に移動

### 年次タブ

- 月別支出の **積み上げ棒グラフ**（年間推移）
- 年間の **カテゴリ別円グラフ**
- **‹ ›** で前後の年に移動

## 3. 資産管理 💰

ホーム右上の **💰** をタップします。

### 残高入力タブ

毎月の各口座・資産の残高を入力します。

| グループ | 内容 |
|---|---|
| 銀行預金 | ゆうちょ・楽天銀行・千葉銀行・財形貯蓄など |
| 保険 | 終身保険・個人年金など |
| 株式資産 | 証券口座の残高 |
| 貴金属資産 | 金・貴金属の残高 |
| 年金残高 | 確定拠出年金・退職金見込み |
| 負債 | 自動車ローン残高など（純資産から差し引かれます） |

各資産カテゴリの右に **利回り%** の入力欄があります。シミュレーションの複利計算に使われます。設定した値はスプレッドシートの「利回り設定」タブに保存され、家族間で共有されます。

入力後、**「💾 保存する」** をタップ。

**「前月の残高を引き継ぐ」**（当月データなしの場合に表示）: 前月の値を入力欄にコピーします。変更分だけ修正して保存できます。

### 収支タブ

月次の収入・支出を入力します。

| 項目 | 説明 |
|---|---|
| 家計（家計簿より） | 家計簿の当月支出合計が自動表示されます（編集不可） |
| 会社給与・賞与など | 手動入力 |
| 各支出科目 | 手動入力 |

各項目の右の **「前月」** ボタンをタップすると、前月の金額を自動入力できます。

入力後、**「💾 保存する」** をタップ。

### 推移グラフタブ

全期間の資産推移をグラフで確認できます（カテゴリ別積み上げ棒グラフ＋純資産ライン）。

### 未保存警告

残高入力・収支タブで入力後に保存せず画面を移動しようとすると、確認ダイアログが表示されます。

## 4. 収支予測 📅

資産管理画面右上の **📅** をタップします。

収入・支出のルールを「期間」で登録します。将来のシミュレーションに使われます。

### 定期ルール（繰り返す収支）

例: 給与、住宅ローン、保険料など。

1. 上部のトグルで **「定期」** を選択（デフォルト）
2. 項目名・収支区分・金額を入力
3. **頻度** を選択:
   - **毎月**: 毎月同額が発生する（月額入力）
   - **毎年**: 年に1回だけ発生する（年額入力・適用月を選択）。例: ボーナス6月、固定資産税5月など
4. 開始年月と終了年月（空欄＝永続）を入力
5. 必要に応じて **振替先口座** を設定（後述）
6. **「＋ 追加」** をタップ

### 一時イベント（特定の月だけ発生する収支）

例: 大学入学金、車の買い替え、リフォームなど。

1. 上部のトグルで **「一時イベント」** を選択
2. 項目名・収支区分・金額・年月を入力
3. **「＋ 追加」** をタップ

### 振替先口座の設定

収支ルールに「振替先口座」を設定することで、資産間の移動を表現できます。

| パターン | 用途例 | 効果 |
|---|---|---|
| 支出 + 振替先あり | 積立NISA、確定拠出年金 | 現金から振替先口座へ移動（純資産は変わらず、振替先が複利成長） |
| 収入 + 振替先あり | 退職金が特定口座に入金 | 振替先口座に直接加算（以後複利成長） |
| 振替先なし | 通常の収入・支出 | 従来通り（収入=現金増、支出=現金減） |

### ルールの編集・削除

登録済みルールの **「編集」** をタップすると、フォームに値が展開されます。修正後 **「✔ 更新」** で保存。**「キャンセル」** で編集を中断します。

**「削除」** をタップすると即座に削除されます。

### カードのバッジ

| バッジ | 意味 |
|---|---|
| 緑「収入」 | 収入ルール |
| 赤「支出」 | 支出ルール |
| 橙「一時」 | 一時イベント |
| 紫「年次」 | 毎年X月に発生するルール |
| 青「振替」 | 振替先口座が設定されている |

## 5. シミュレーション 🧮

資産管理画面右上の **🧮** をタップします。

直近月の資産残高を起点に、収支予測ルールと利回り設定を反映した **2070年12月までの資産推移グラフ** を表示します。

- **実線（緑）**: 実績（現在までの資産データから算出）
- **破線（薄緑）**: 予測（収支ルールと複利成長を適用した将来分）
- **赤い縦線**: 一時イベントの発生タイミング

### 利回りの反映

残高入力タブで設定した各カテゴリの利回り%が複利計算に使われます。利回りが設定されている場合、グラフ上部に「想定利回り反映済み」と表示されます。

- 資産カテゴリごとに異なる利回りを設定できます（例: 楽天証券 3%、確定拠出年金 3%、銀行 0%）
- 負債カテゴリには複利成長は適用されません
- 振替先に設定した口座は振替金額が入金された後、その口座の利回りで成長します

### グラフの操作

| 操作 | 方法 |
|---|---|
| ズームイン | ピンチアウト（モバイル）/ **＋** ボタン（PC） |
| ズームアウト | ピンチイン（モバイル）/ **−** ボタン（PC） |
| スクロール | 左右スワイプ（モバイル）/ **◀ ▶** ボタン（PC） |
| 全期間表示に戻す | **「全期間」** ボタン |

収支予測ルールを先に登録してからシミュレーションを開くと、より正確な予測になります。

> **シミュレーションの精度について**: 収入ルールと支出ルールの合計が実態に近いほど正確になります。給与・生活費・税金・保険・教育費など、主要な収支をすべて登録することをおすすめします。

## スプレッドシートを直接確認する

ホーム右上の **📊** をタップするとGoogle Sheetsが開きます。

### シートの構成

| タブ名 | 内容 |
|---|---|
| `2026.1`〜`2026.12` | 月別の家計簿データ |
| `資産管理` | 月次の資産・負債残高 |
| `キャッシュフロー` | 月次の収入・支出 |
| `収支予測` | 収入・支出の期間ルール（毎月/毎年/一時イベント・振替先含む） |
| `利回り設定` | 資産カテゴリ別の年間利回り% |
